C++ Maps & Unordered Maps

Maps are associative containers that store elements in Key-Value pairs. Each key must be unique.

  • std::map: Implemented as a Red-Black Tree. Keys are automatically sorted. Slower access (O(log n)).
  • std::unordered_map: Implemented as a Hash Table. Keys are unordered. Faster access (O(1)).

1. Insertion & Access Methods

There are multiple ways to insert Key-Value pairs into a map. It is important to know the difference between accessing them with the bracket operator [] versus the .at() function.

Crucial Rule: The .at() function is strict. It is used only for retrieval or updating. If the key doesn't exist, it throws an error. The [] operator is lenient: if the key doesn't exist, it will automatically insert it with a default value! 
#include <iostream>
#include <unordered_map>
using namespace std;

int main() {
    unordered_map<string, string> table;

    // Insertion Way 1: Using the bracket operator (Easiest & Most Common)
    table["in"] = "India";
    
    // Insertion Way 2: Using insert() with make_pair
    table.insert(make_pair("br", "Brazil"));
    
    // Insertion Way 3: Creating a pair object manually
    pair<string, string> p;
    p.first = "en";
    p.second = "England";
    table.insert(p);
    
    // Insertion Way 4: Modern C++ Initializer List
    table.insert({"jp", "Japan"});

    // Accessing elements
    cout << table["in"] << endl;    // Outputs: India
    cout << table.at("br") << endl; // Outputs: Brazil

    // Basic Methods
    cout << "Size: " << table.size() << endl; 
    // table.clear(); // empties the map
    // cout << table.empty(); // returns 1 if empty, 0 otherwise

    return 0;
}

2. Searching: find() vs count()

Because the [] operator silently inserts missing keys, you should never use it just to check if a key exists. Instead, use find() or count().

Undefined Behavior Warning: table.find("key") returns an iterator. If the key is not found, it returns table.end(). If you try to blindly print the result without checking, you will dereference an invalid iterator and crash your program! 
#include <iostream>
#include <map>
using namespace std;

int main() {
    map<string, int> scores;
    scores["Alice"] = 95;
    scores["Bob"] = 80;

    // METHOD 1: Using count() 
    // Returns 1 if key exists, 0 if it doesn't (since keys are unique)
    cout << "Does Charlie exist? " << scores.count("Charlie") << endl; // 0

    // METHOD 2: Using find() (The safest and most standard way)
    auto it = scores.find("Alice");
    
    if (it != scores.end()) {
        // Safe to access
        cout << "Found Alice! Score: " << it->second << endl;
    } else {
        cout << "Key not found!" << endl;
    }

    // cout << (*(scores.find("Charlie"))).first << endl; // ❌ CRASH! UNDEFINED BEHAVIOR!

    return 0;
}

3. Traversing a Map

When traversing a map, the iterator points to a std::pair. You access the key using first and the value using second.
Tip: Use the arrow operator it->first instead of dereferencing (*it).first for cleaner code.

#include <iostream>
#include <map>
using namespace std;

int main() {
    // Note: Because this is an ORDERED map, the output will 
    // automatically be sorted alphabetically by the keys!
    map<string, string> table;
    
    table["in"] = "India";
    table["br"] = "Brazil";
    table["en"] = "England";
    table["au"] = "Australia";

    cout << "--- Using Iterator (While Loop) ---" << endl;
    auto it = table.begin();
    while (it != table.end()) {
        // it->first is the key, it->second is the value
        cout << it->first << " : " << it->second << endl;
        it++;
    }

    cout << "\n--- Using Range-Based For Loop (Modern C++) ---" << endl;
    for (auto const& pair : table) {
        cout << pair.first << " : " << pair.second << endl;
    }
    
    /* 
    OUTPUT (Alphabetically sorted by key):
    au : Australia
    br : Brazil
    en : England
    in : India
    */

    return 0;
}
