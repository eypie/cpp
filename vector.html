C++ Vectors

A comprehensive guide to standard template library (STL) vectors in C++, detailing initialization, element access, capacity management, and multidimensional usage.

1. Initialization & Basic Operations

Vectors are dynamic arrays. Here is how to create them, add/remove elements, and check their properties.

Key Functions:
push_back(val): Appends an element.
pop_back(): Removes the last element.
size(): Returns the number of elements. 
#include <iostream>
#include <vector>
using namespace std;

int main() {
    // 1. Initializations
    vector<int> marks;                   // Empty vector
    vector<int> miles(10);               // 10 blocks, initialized to 0
    vector<int> scores(10, 5);           // 10 blocks, initialized to 5

    // 2. Modifying Elements
    scores.push_back(20);                // Appends 20 to the end
    scores.pop_back();                   // Removes the last element

    // 3. Properties and Access
    cout << "Size: " << scores.size() << endl;
    cout << "Capacity: " << scores.capacity() << endl;
    
    cout << "First Element: " << scores.front() << endl; 
    cout << "Last Element: " << scores.back() << endl; 
    cout << "Is Empty? (1=True, 0=False): " << scores.empty() << endl;

    // 4. Accessing Specific Indexes
    cout << scores[1] << endl;           // Unsafe access (no bounds check)
    cout << scores.at(1) << endl;        // Safe access (throws exception if out of bounds)

    return 0;
}

2. Size vs. Capacity & Memory Management

Size is the current number of elements. Capacity is the total space currently allocated in memory. When a vector runs out of capacity, it typically doubles its capacity (allocating a new contiguous block of memory and moving elements).

Pro Tip: Use reserve() if you know exactly how many elements you will insert. This prevents expensive background reallocations. 
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> marks;
    
    // Pre-allocate memory to avoid background reallocations
    marks.reserve(20);
    
    cout << "Current Size: " << marks.size() << endl;       // 0
    cout << "Reserved Capacity: " << marks.capacity() << endl; // 20

    // Modifying elements using iterators
    marks = {10, 20, 30, 40};
    
    marks.insert(marks.end() - 1, 900); // Inserts 900 before the last element
    marks.erase(marks.begin());         // Erases the first element
    
    // Erase a range (clears the entire vector here)
    marks.erase(marks.begin(), marks.end()); 
    // This is equivalent to: marks.clear();

    cout << "Max possible size: " << marks.max_size() << endl;

    return 0;
}

3. Swapping Vectors

You can easily swap the contents of two vectors. This operation is highly efficient because it only swaps the internal memory pointers, rather than copying elements one by one.

#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> first = {1, 2, 3, 4, 5, 6, 7};
    vector<int> second = {8, 9, 10, 11};

    // Both methods below work perfectly:
    // swap(first, second); 
    second.swap(first); 

    cout << "First vector contents: ";
    for (int i : first) {
        cout << i << " ";
    }
    cout << endl;

    return 0;
}

4. Iterators and Looping

Iterators behave like pointers to the elements inside the vector. They are essential for functions like insert(), erase(), and for traversing.

#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> marks = {10, 20, 30, 40};

    cout << "Using For Loop: " << endl;
    for (vector<int>::iterator it = marks.begin(); it != marks.end(); it++) {
        cout << *(it) << " ";
    }
    
    cout << "\nUsing While Loop: " << endl;
    vector<int>::iterator it = marks.begin();
    while (it != marks.end()) {
        cout << *it << " ";
        it++;
    }

    return 0;
}

5. 2D Vectors & Jagged Arrays

A 2D vector is simply a vector containing other vectors. They are heavily used to create matrices. Unlike standard 2D arrays, 2D vectors can be "jagged" (uneven), meaning each row can have a completely different number of columns.

#include <iostream>
#include <vector>
using namespace std;

int main() {
    // Uniform Matrix: 5 rows, 4 columns, all initialized to 0
    vector<vector<int>> matrix(5, vector<int>(4, 0)); 
    
    cout << "Rows: " << matrix.size() << endl;
    cout << "Columns: " << matrix[0].size() << endl;

    // Manual Assignment of a Jagged Matrix
    vector<vector<int>> v(4); 
    v[0] = vector<int>(3, 0); // 1st row has 3 columns
    v[1] = vector<int>(6, 0); // 2nd row has 6 columns
    v[2] = vector<int>(1, 0); // 3rd row has 1 column
    v[3] = vector<int>(5, 0); // 4th row has 5 columns

    // Initializer list with uneven rows
    vector<vector<int>> uneven = {
        {1, 2, 3},
        {1, 2},
        {3, 4, 4, 5, 6}
    };

    // Range-based for loop to print 2D vector
    for (vector<int> row : uneven) {
        for (int val : row) {
            cout << val << " ";
        }
        cout << "\n";
    }

    return 0;
}
