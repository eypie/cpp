C++ Stacks (std::stack)

A Stack is a Container Adapter that operates strictly on the Last-In, First-Out (LIFO) principle. Think of it like a stack of plates: the last plate you place on top is the first one you take off.

1. Basic Operations: Push, Pop & Top

In a stack, all insertions and deletions happen exclusively at one end, known as the "top".

Key Concept: s.top() only reads the top element. It does not remove it. To remove the element, you must call s.pop() separately. 
#include <iostream>
#include <stack>
using namespace std;

int main() {
    stack<int> s;
    
    s.push(10);
    s.push(20);
    s.push(30);
    s.push(40); // 40 is now at the top

    cout << "Top element: " << s.top() << endl;    // 40
    cout << "Stack size: " << s.size() << endl;    // 4
    cout << "Is Empty? " << s.empty() << endl;     // 0 (False)

    s.pop(); // Removes the top element (40)
    cout << "New Top element: " << s.top() << endl; // 30

    return 0;
}

2. Emplace vs Push

In addition to push(), C++11 introduced emplace(). While they do the same thing for simple data types like integers, emplace() is more efficient for complex objects (like custom classes or structs) because it constructs the element directly inside the stack, avoiding unnecessary copies.

#include <iostream>
#include <stack>
using namespace std;

int main() {
    stack<int> s;
    
    // Standard push
    s.push(100); 

    // Emplace - slightly faster for complex objects under the hood
    s.emplace(200); 
    
    cout << "Top is now: " << s.top() << endl; // 200

    return 0;
}

3. Swapping Stacks

Just like Vectors and Queues, you can swap the entire contents of two stacks instantly using the swap() function.

#include <iostream>
#include <stack>
using namespace std;

int main() {
    stack<int> s1;
    s1.push(1);
    s1.push(2);
    
    stack<int> s2;
    s2.push(99);
    s2.push(100);

    // Swap the contents of s1 and s2
    s1.swap(s2); // or swap(s1, s2);

    cout << "s1 top after swap: " << s1.top() << endl; // 100
    cout << "s2 top after swap: " << s2.top() << endl; // 2

    return 0;
}

4. Traversing / Printing a Stack

Crucial Rule: Stacks do not have iterators. You cannot use a for loop or index them like an array (e.g., s[0]). The only way to view all elements is to pop them off one by one. 
#include <iostream>
#include <stack>
using namespace std;

int main() {
    stack<int> s;
    s.push(10);
    s.push(20);
    s.push(30);

    cout << "Emptying stack: ";
    
    // Standard idiom for processing a stack
    while (!s.empty()) {
        cout << s.top() << " "; // Print top
        s.pop();                // Remove top
    }
    // Output: 30 20 10
    
    // Warning: The stack 's' is now completely empty!
    cout << "\nSize after printing: " << s.size() << endl; // 0

    return 0;
}
