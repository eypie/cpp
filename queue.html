C++ Queues, Deques & Priority Queues

A complete guide to sequential containers that manage elements based on specific ordering rules: FIFO (Queue), double-ended access (Deque), and heap-based sorting (Priority Queue).

1. Queue (std::queue)

A Queue operates strictly on the First-In, First-Out (FIFO) principle. Elements are pushed to the back and popped from the front.

Key Limitations: Unlike Vectors or Deques, standard queues do not support indexing (e.g., q[0] is invalid) and do not support iteration (you cannot use a for-loop on a queue). To traverse a queue, you must pop elements one by one. 
#include <iostream>
#include <queue>
using namespace std;

int main() {
    queue<int> q;
    
    // Pushing elements to the back
    q.push(10);
    q.push(20);
    q.push(30);
    q.push(40);

    cout << "Front: " << q.front() << endl; // 10
    cout << "Back: " << q.back() << endl;   // 40

    q.pop(); // Removes the first element (10)
    cout << "New Front: " << q.front() << endl; // 20

    cout << "Size: " << q.size() << endl;
    cout << "Is Empty? " << q.empty() << endl;

    // Swapping Queues
    queue<int> q1, q2;
    for (int i : {1, 2, 3}) q1.push(i);
    for (int i : {10, 20, 30, 40}) q2.push(i);
    
    swap(q1, q2); 
    // Now q1 has {10, 20, 30, 40} and q2 has {1, 2, 3}

    return 0;
}

2. Deque (std::deque)

A Deque (Double-Ended Queue) is a versatile container that combines the best features of Vectors and Lists. It allows fast insertion and deletion at both the front and the back, while still supporting random access indexing.

Pro Tip: Unlike Lists, Deques use continuous blocks of memory under the hood, making them cache-friendly while maintaining constant-time insertions at both ends! 
#include <iostream>
#include <deque>
using namespace std;

int main() {
    // Initialization
    deque<int> dq = {10, 20, 30};

    // Indexing is allowed!
    cout << "Index 0: " << dq[0] << endl;       // 10
    cout << "Using .at(): " << dq.at(1) << endl; // 20

    // Modifying both ends
    dq.push_back(40);
    dq.push_front(0);
    // dq is now: {0, 10, 20, 30, 40}

    dq.pop_back();   // Removes 40
    dq.pop_front();  // Removes 0

    // Successful Iteration (Range-based for loop works!)
    cout << "Deque elements: ";
    for (int i : dq) {
        cout << i << " ";
    }
    cout << endl;

    // Iterator Arithmetic Works
    cout << "Second element: " << *(dq.begin() + 1) << endl;
    cout << "Last element: " << *(dq.end() - 1) << endl;

    // Insertion & Deletion using Iterators
    dq.insert(dq.begin(), 100);       // Insert at front
    dq.insert(dq.end(), 500);         // Insert at back

    dq.erase(dq.begin());             // Erase first element
    
    // NOTE: dq.erase(dq.end()) is DANGEROUS! end() is out of bounds.
    // Use dq.erase(dq.end() - 1) to erase the last element.

    return 0;
}

3. Priority Queue (std::priority_queue)

A Priority Queue is implemented as a Heap data structure. By default, it acts as a Max-Heap, meaning the largest element is automatically sorted to the top.

Key Concept: Pushing an element will automatically place it in the correct order based on priority. Like a standard Queue, there is no iteration—you can only access the top() element. 
#include <iostream>
#include <queue>
using namespace std;

int main() {
    // 1. DEFAULT: MAX-HEAP
    // (Largest element stays at the top)
    priority_queue<int> pq; 
    
    pq.push(10); // {10}
    pq.push(9);  // {10, 9}
    pq.push(20); // {20, 10, 9}
    pq.push(15); // {20, 15, 10, 9}

    cout << "Max-Heap Top: " << pq.top() << endl; // 20
    pq.pop(); // Removes 20

    cout << "New Top: " << pq.top() << endl;      // 15
    pq.pop(); // Removes 15

    // 2. MANUAL: MIN-HEAP
    // (Smallest element stays at the top)
    priority_queue<int, vector<int>, greater<int>> min_heap;
    
    min_heap.push(50);
    min_heap.push(10);
    min_heap.push(30);

    cout << "Min-Heap Top: " << min_heap.top() << endl; // 10

    return 0;
}
