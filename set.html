C++ Sets & Unordered Sets

A Set is a container that stores unique elements. If you try to insert a duplicate value, the Set will simply ignore it.

  • std::set: Elements are automatically sorted in ascending order (implemented via Red-Black Trees).
  • std::unordered_set: Elements are unsorted, but insertion and lookup are much faster (O(1) average time, implemented via Hash Tables).

1. Insertion & Uniqueness

When you insert elements into a set, it automatically filters out duplicates.

#include <iostream>
#include <unordered_set>
using namespace std;

int main() {
    // Notice the duplicate '2' in the initializer list
    unordered_set<int> st = {1, 2, 2, 3, 4}; 
    
    st.insert(10);
    st.insert(20);
    st.insert(30);
    
    // Trying to insert a duplicate value
    st.insert(20); // This will be ignored!

    // The size will be 7, not 9, because duplicates were discarded.
    cout << "Size: " << st.size() << endl; 
    
    cout << "Is Empty? " << st.empty() << endl;

    // st.clear(); // This would empty the entire set

    return 0;
}

2. Traversing a Set

Because sets are not indexed like arrays, you cannot use st[0]. You must use iterators or a range-based for loop.

#include <iostream>
#include <set>
using namespace std;

int main() {
    // Using a regular ordered set this time
    set<int> st = {30, 10, 40, 20}; 
    
    cout << "1. Range-based for loop (Cleanest):" << endl;
    for (int i : st) {
        cout << i << " "; // Output: 10 20 30 40 (Automatically sorted!)
    }
    cout << "\n\n";

    cout << "2. Using a standard For Loop with Iterators:" << endl;
    for (auto it = st.begin(); it != st.end(); it++) {
        cout << *it << " ";
    }
    cout << "\n\n";

    cout << "3. Using a While Loop with Iterators:" << endl;
    set<int>::iterator it = st.begin();
    while (it != st.end()) {
        cout << *it << " ";
        it++;
    }
    cout << endl;

    return 0;
}

3. Searching & Erasing Elements

Sets are highly optimized for checking if an element exists. You should use find() or count().

Key Concept: count() is extremely useful in sets. Because all elements are unique, count(val) will strictly return 1 if the value exists, and 0 if it does not. It effectively acts as a boolean check. 
#include <iostream>
#include <unordered_set>
using namespace std;

int main() {
    unordered_set<int> st = {10, 20, 30, 40, 50};

    // --- SEARCHING ---
    
    // Method 1: Using count() (Easiest way to check existence)
    cout << "Is 30 present? " << st.count(30) << endl; // 1 (True)
    cout << "Is 99 present? " << st.count(99) << endl; // 0 (False)

    // Method 2: Using find()
    // find() returns an iterator to the element. If not found, it returns st.end()
    if (st.find(20) != st.end()) {
        cout << "20 was found in the set!" << endl;
    }

    // You can also cast the comparison directly to a boolean
    bool exists = (st.find(13) != st.end());
    cout << "Does 13 exist? " << exists << endl; // 0 (False)


    // --- ERASING ---
    
    // Erasing by value directly
    st.erase(40);
    
    // Erasing using an iterator
    auto it = st.find(10);
    if (it != st.end()) {
        st.erase(it);
    }

    cout << "Set after erasing 40 and 10: ";
    for (int i : st) cout << i << " ";
    cout << endl;

    return 0;
}
