C++ Lists (std::list)

In C++, std::list is a Doubly Linked List. Unlike vectors (which use contiguous memory), list elements are scattered in memory and connected via pointers. This makes inserting/removing elements in the middle very fast, but direct element access (like nums[2]) impossible.

1. Basic Operations: Push, Pop, & Info

Because it's a doubly linked list, you can efficiently add and remove elements from both the front and the back.

#include <iostream>
#include <list>

using namespace std;

int main() {
    list<int> numbers = {10, 20, 30, 40};

    // Adding elements to both ends
    numbers.push_back(50);   // {10, 20, 30, 40, 50}
    numbers.push_front(1);   // {1, 10, 20, 30, 40, 50}
    
    // Removing elements from both ends
    numbers.pop_back();      // Removes 50
    numbers.pop_front();     // Removes 1

    // Basic List Info
    cout << "Size: " << numbers.size() << endl; 
    cout << "Is Empty? " << numbers.empty() << endl; 
    cout << "First: " << numbers.front() << " | Back: " << numbers.back() << endl;

    // numbers.clear(); // This would empty the entire list

    return 0;
}

2. Iterating & Removing Elements

Crucial Concept: Lists use Bidirectional Iterators, not Random Access Iterators.
You cannot do pointer arithmetic like numbers.end() - 1 or it + 2. You must step through memory one node at a time using it++ or it--. 
#include <iostream>
#include <list>

using namespace std;

int main() {
    list<int> numbers = {10, 20, 30, 40};
    numbers.push_back(10); // List is now: 10 -> 20 -> 30 -> 40 -> 10

    // Traversing using a while loop
    cout << "List contents: ";
    list<int>::iterator it = numbers.begin();
    while(it != numbers.end()) {
        cout << *it << " ";
        it++;
    }
    cout << "\n";

    // remove(val) removes ALL occurrences of 'val' in the list
    numbers.remove(10); 
    
    // Traversing using a for loop
    cout << "After removing 10s: ";
    for(auto i = numbers.begin(); i != numbers.end(); i++) {
        cout << *i << " ";
    }
    cout << "\n";
    
    return 0;
}

3. Advanced Iteration: std::next & std::prev

Because we can't use + or - with list iterators, C++ provides std::next() and std::prev() to safely advance iterators.

Warning about end(): The .end() iterator points to one-step past the last element. Dereferencing *nums.end() results in undefined behavior. You must step back by one to get the actual last element. 
#include <iostream>
#include <list>
#include <iterator> // needed for std::next and std::prev

using namespace std;

int main() {
    list<int> nums = {10, 20, 30, 40, 50};

    // 1. Getting specific elements from the start
    cout << "1st element: " << *nums.begin() << endl;              // 10
    cout << "2nd element: " << *next(nums.begin()) << endl;        // 20
    cout << "3rd element: " << *next(nums.begin(), 2) << endl;     // 30

    // 2. Getting specific elements from the end
    cout << "Last element: " << *prev(nums.end()) << endl;         // 50
    cout << "2nd to last: " << *prev(nums.end(), 2) << endl;       // 40

    // 3. Inserting an element using advanced iterators
    // Syntax: list_name.insert(iterator_position, element)
    
    // nums.insert(nums.end() - 1, 100); // ❌ THIS WILL CAUSE AN ERROR!
    nums.insert(prev(nums.end()), 100);  // ✅ CORRECT WAY (Inserts before 50)

    cout << "After insertion: ";
    for (int x : nums) {
        cout << x << " ";
    }
    // Output: 10 20 30 40 100 50

    return 0;
}

4. Swapping Lists

Just like Vectors, you can easily swap the contents of two lists. Because of how linked lists work, this operation simply swaps the internal head/tail pointers, making it incredibly fast regardless of the list size.

#include <iostream>
#include <list>

using namespace std;

int main() {
    list<int> ls1 = {1, 2, 3, 4};
    list<int> ls2 = {5, 6, 7};

    // Both methods work:
    // swap(ls1, ls2);
    ls2.swap(ls1);

    cout << "List 1: ";
    for(int x : ls1) { cout << x << " "; }
    
    cout << "\nList 2: ";
    for(int x : ls2) { cout << x << " "; }
    cout << "\n";

    return 0;
}
